# 🌐 Página Pessoal - Yago Dinato

Seja bem-vindo ao repositório do meu portfólio pessoal! Este projeto foi desenvolvido para apresentar meu perfil, minhas experiências e minha jornada no mercado de Tecnologia da Informação.

---

## 🚀 Sobre o Projeto

Este é um site responsivo e moderno construído com foco em simplicidade e boa navegação. Ele conta com um efeito dinâmico de digitação no título principal, destacando minhas áreas de atuação e estudos.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** — Estruturação do conteúdo.
- **Bootstrap 5.3** — Estilização, componentes e responsividade.
- **JavaScript (ES6+)** — Lógica do efeito de digitação (*typing effect*) e controle do cursor.

---

## ✨ Funcionalidades

- **Header de Navegação:** Botões rápidos de navegação (About, Experience, Projects, Contact).
- **Efeito Efeito Digitação:** Animação em JavaScript que alterna entre as frases *"Estudante de ADS"* e *"Téc Instrumentista"*.
- **Card Principal:** Apresentação pessoal, breve bio e foto de perfil responsiva.
- **Layout Responsivo:** Adaptado para telas de celular, tablet e computador.
